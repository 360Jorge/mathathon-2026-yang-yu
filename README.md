# Mathathon 2026 — Yang–Yu Algorithm 7.6 reproducibility study

**Track:** Geometry  
**Participant:** Jorge Guzman  
**Status:** Reproduction of published examples; not a new classification.

We investigate a Python implementation of Yang–Yu Algorithm 7.6 for intersections of Hassett divisors, especially C₈ ∩ C₁₄. The code reproduces the published component counts 17, 6, and 5 for three test intersections. See `report.pdf` for precise claims, citations, and limitations.

## Contents
- `report.tex`, `report.pdf`: self-contained submission report
- `slides.pdf`: required presentation
- `slides.tex`: editable presentation source
- `algo76.py`: AI-generated computational implementation
- `requirements.txt`: Python dependencies
- `check_output.txt`: recorded execution output

## Reproduce
```bash
python -m pip install -r requirements.txt
python algo76.py --check
```

**Verification status:** Successful regression checks are not a proof of general correctness. The algorithm has finite search bounds, uses floating-point eigenvalues for vector search, and does not fully certify all rejected overlattices. See report.
